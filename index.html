Automated Real Estate Valuation Model

Machine learning regression system to predict residential property prices in King County, Washington using more than 21,000 historical sales records.

Approach

  • Performed data cleaning, exploration and preprocessing.
  • Engineered features including property age, renovation status and geographic information.
  • Compared multiple regression algorithms: Linear Regression, Random Forest, XGBoost, LightGBM and CatBoost.
  • Optimized CatBoost hyperparameters using Optuna.
  • Applied SHAP explainability techniques to analyze feature impact.

Results

  • R²: 0.918
  • MAE: approximately $61,193
  • MAPE: 11.1%

Technologies: Python · Pandas · Scikit-learn · CatBoost · XGBoost · LightGBM · Optuna · SHAP
